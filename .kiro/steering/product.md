# Product steering — Haunted Terminal

- Read-only, no custody: never ask for a wallet, seed, private key, or
  signature. Never trade, swap, mint, or auto-buy.
- Never invent data: if a source returns nothing, show `unverified` / fog.
- Every number carries its source + fetch time.
- Spooky UI must encode risk (tombstone height, glow, aura colour),
  never just decorate. If a visual does not carry information, cut it.
- Trading views carry a risk warning. No promise of returns.
